Bangalore Weather Prediction

Project Description:
This mini project predicts the next day's temperature in Bangalore using historical weather data obtained from the Open-Meteo API.

Technologies Used:
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Open-Meteo API
Machine Learning Algorithm
Linear Regression

Features:
- Temperature
- Humidity
- Pressure
- Wind Speed
- Previous day's weather conditions

Model Evaluation:
The model is evaluated using:
- MAE
- MSE
- RMSE
- R² Score

Project Outputs:
- Temperature trend visualization
- Weather feature correlation heatmap
- Actual vs predicted temperature graph
- Next-day temperature prediction
